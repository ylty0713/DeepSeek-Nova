# DeepSeek Nova 2.1.88 使用说明

## 界面布局

- 左侧：新建任务、历史任务、归档、搜索、工作区和设置。
- 中间：连续对话、附件、阶段摘要、审批卡片、消息队列和最终结果。
- 右侧：完整任务进程、工作区文件、文件内容、媒体预览和内置浏览器；左右侧栏均可收起。

## 第一次使用

1. 打开左下角“设置”。
2. 填写 DeepSeek API Key。
3. 选择主模型、快速模型和推理强度。
4. 选择审批模式。需要逐项确认时使用受控模式；确认信任当前任务和工作区后，才使用“完全访问”。
5. 返回首页，新建任务并输入需求；也可以先添加文件。

## 开发与检查

```powershell
cd desktop
npm install
npm run check
```

公开仓库不附带第三方运行时。任务执行前，需要按照 `RUNTIME_ADAPTER.md` 接入你有权使用的运行时；未配置时仅提供界面开发与预览能力。

## 数据与隐私

API Key、任务记录和用户偏好保存在本机，不应提交到 GitHub。删除会话时，对应的本地消息和任务进程也会一并删除。
